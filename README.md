# Story Rewrite: Remaster

A self-contained, choice-driven visual novel built with HTML, CSS, and JavaScript. It deploys directly on GitHub Pages.

## Play

Open `index.html`, or enable GitHub Pages in **Settings → Pages → Deploy from branch** and select `main`.

## Features

- Branching dialogue choices
- Multiple endings
- Atmospheric character and scene art
- Save/load through browser storage
- Responsive mobile and desktop layout

The game is intentionally dependency-free and requires no build process.
